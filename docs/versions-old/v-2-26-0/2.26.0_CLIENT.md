# v2.26.0 — Changements visibles client

Retrait des dépréciations des rappels unifiés (task #497, suite de #487 / v2.22.0). Les
remplaçants existent depuis v2.22.0 ; aucun appel aux routes retirées n'a été relevé dans les
journaux de production du 14 au 20 novembre 2026.

## BREAKING CHANGES

- Routes retirées → `404` :
  - `GET|PUT /push/preferences` → utiliser `GET|PUT /notifications/defaults` et
    `/notifications/devices` ;
  - `GET /notifications/email`, `DELETE /notifications/email/{id}`,
    `POST /notifications/email/test`, `POST /notifications/send-email` → les rappels courriel
    sont planifiés par le cron unifié à partir du champ `notifications` des éléments.
- Tâches de projet (`/projets/...`) :
  - `rappelMinutesAvant` n'est plus renvoyé (GET, liste, `export.json`) ;
  - `POST` / `PATCH` avec `rappelMinutesAvant` → `422`, `errors.code = FIELD_REMOVED`,
    `errors.field = rappelMinutesAvant` → utiliser `notifications` ;
  - import JSON : le champ est ignoré, les anciens exports restent importables.
- `GET /users/me/notification-preferences` : `notification_email` n'est plus renvoyé ;
  `PUT` avec ce champ → `422 FIELD_REMOVED`. Les rappels partent à l'adresse du compte.
