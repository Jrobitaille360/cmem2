# v2.17.2 — Changements visibles client

## Corrigé

### Lien d'invitation groupe pointait vers le mauvais domaine

Directive cmem_web, task cmemweb #195.

Le courriel d'invitation à un groupe (`POST /groups/{id}/invite`) contenait un lien
pointant vers le domaine de l'API cmem2 avec une méthode GET, alors que
`/groups/join` n'accepte cette requête qu'en POST côté client. Le clic sur le lien
produisait un message trompeur (« Utilisateur non authentifié ») au lieu de faire
rejoindre le groupe.

`invite_url` pointe maintenant vers le domaine du client web (`CMEMWEB_APP_URL`) :

```text
{CMEMWEB_APP_URL}/groups/join?email={email}&role={role}&code={invitationToken}
```

Le frontend cmem_web est responsable de construire une page `/groups/join` qui lit
ces paramètres et effectue elle-même le `POST /groups/join` avec `{code, email, role}`
(livré séparément côté cmem_web).

## BREAKING CHANGES

Aucun.
