# v2.17.5 — Changements visibles client

## Corrigé

### Statut premium fiable après action Stripe

Après une mise à jour ou une annulation d'abonnement côté Stripe, le statut premium du
compte (`is_premium`) reflète maintenant correctement l'état de l'abonnement immédiatement
— corrige un cas où le statut restait désynchronisé après un événement webhook.

## BREAKING CHANGES

Aucun. Le webhook Stripe (`POST v2/billing/webhook`) est appelé par Stripe, pas par les
clients cmem_web/Flutter — l'ajout des champs `data.received`/`data.skipped` dans sa réponse
n'affecte aucune app cliente.
