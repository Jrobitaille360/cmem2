# Déploiement production — v2.3.1

---

## Pré-requis

- v2.3.0 déjà en production
- MySQL 5.7+ ou MariaDB 10.3+
- PHP 8.0+

---

## Checklist de déploiement

### 1. Sauvegarde préalable

```bash
mysqldump -u root cmem2_db > backup_before_2.3.1_$(date +%Y%m%d_%H%M%S).sql
```

### 2. Migration base de données

```sql
ALTER TABLE files MODIFY COLUMN media_type
  ENUM('text','audio','video','image','gpx','summary','event','todo','document','executable')
  DEFAULT NULL;
```

> La migration est **non destructive** : ajout d'une valeur à un enum existant.

### 3. Déploiement du code

```bash
git pull origin main
# Aucun composer install requis — aucune nouvelle dépendance
```

Ou via le script de déploiement SSH :

```powershell
.\private\deploy.ps1
```

### 4. Vérification post-déploiement

```bash
# Items publics sans JWT
curl -s https://cmem2.journauxdebord.com/items/publics | jq .success
# Attendu : true

# Upload vers un dossier personnalisé (token admin requis)
curl -s -X POST https://cmem2.journauxdebord.com/files \
  -H "Authorization: Bearer <token_admin>" \
  -F "file=@test.zip" \
  -F "folder=test-deploy" | jq .data.file.url
# Attendu : "/uploads/test-deploy/<uuid>_test.zip"

# Liste du dossier (admin)
curl -s "https://cmem2.journauxdebord.com/files?folder=test-deploy" \
  -H "Authorization: Bearer <token_admin>" | jq .data.total
# Attendu : 1
```

### 5. Tests fonctionnels

```bash
php private/tests_mine/test_items.php
# Attendu : OK sur /items/publics et /items/{id} sans JWT

php private/tests_mine/test_files.php
# Attendu : OK
```

---

## Rollback

En cas de problème :

```sql
-- Revenir à l'enum sans 'executable' (les enregistrements 'executable' seraient perdus)
ALTER TABLE files MODIFY COLUMN media_type
  ENUM('text','audio','video','image','gpx','summary','event','todo','document')
  DEFAULT NULL;
```

```bash
git checkout v2.3.0
```
