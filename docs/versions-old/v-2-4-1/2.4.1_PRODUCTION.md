# v2.4.1 — Checklist déploiement production

## Migrations SQL

- [ ] Appliquer `docs/v-2-4-1/20260430_files_accessibility.sql`

```bash
mysql -u root -p cmem2_db < docs/v-2-4-1/20260430_files_accessibility.sql
```

La migration ajoute `accessibility ENUM('public','private') NOT NULL DEFAULT 'private'`
sur la table `files`. Les fichiers existants reçoivent `private` par défaut — aucun
impact sur les accès existants.

## Vérifications post-déploiement

- [ ] `GET /health` → `200 OK`
- [ ] `POST /files` (avec `accessibility=public`) → `201` avec `accessibility` dans la réponse
- [ ] `POST /files` (sans paramètre `accessibility`) → `201` avec `accessibility=private`
- [ ] `GET /files/{id}` depuis un compte non-propriétaire sur un fichier `private` → `403`
- [ ] `PATCH /files/{id}/accessibility` (propriétaire) → `200`
- [ ] `PATCH /files/{id}/accessibility` (non-propriétaire) → `403`
