## Changements cassants

**Aucun changement cassant dans cette version.**

La v2.2.5 est rétrocompatible avec la v2.2.4.

## Correctifs côté serveur (transparent pour les clients)

### Plugin Puzzle — debug bypass Premium

Un flag `PUZZLE_DEBUG_PREMIUM` a été ajouté côté serveur pour contourner la vérification
d'abonnement en environnement de développement. Ce flag est désactivé en production.

> **Impact client :** aucun. Si vous receviez une erreur `403 SUBSCRIPTION_REQUIRED` en
> mode debug alors que votre `purchase_token` n'était pas encore validé par Google Play,
> le serveur de développement accepte maintenant vos requêtes premium sans validation.

### Système de backup

Refonte complète des scripts de sauvegarde automatique — aucun impact sur l'API publique.

---

## Rappel — Validation d'abonnement Google Play

Pour activer le Premium dans l'application Puzzle, l'appel suivant doit être fait avant
d'utiliser un endpoint premium (`/puzzle/carousel/replace-all`, `/puzzle/themes`, etc.) :

```
POST /puzzle/auth/verify-subscription
Authorization: Bearer <device_token>

{
  "purchase_token": "<token Google Play>",
  "product_id": "premium_monthly"
}
```

Valeurs acceptées pour `product_id` :

| Valeur | Plan |
| - | - |
| `premium_monthly` | Mensuel |
| `premium_yearly` | Annuel |

**Réponse `200` :**

```json
{
  "success": true,
  "message": "Abonnement actif",
  "data": {
    "is_premium": true,
    "product_id": "premium_monthly",
    "expires_at": "2026-05-11T12:00:00+00:00"
  }
}
```
