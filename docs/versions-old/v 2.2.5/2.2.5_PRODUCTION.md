# Déploiement production — v2.2.5

Checklist à suivre dans l'ordre pour mettre en production la version 2.2.5.

> **v2.2.5 est une version de maintenance.** Aucune migration SQL requise.

---

## 1. Migration SQL

**Aucune migration SQL pour cette version.**

Le schéma de base de données est identique à la v2.2.4.

---

## 2. Variables d'environnement

### Variable à NE PAS ajouter en production

| Variable | Valeur dev | Valeur prod |
| - | - | - |
| `PUZZLE_DEBUG_PREMIUM` | `true` | *(absent ou `false`)* |

> **IMPORTANT :** `PUZZLE_DEBUG_PREMIUM=true` désactive la vérification d'abonnement
> Google Play pour toutes les routes premium Puzzle. Ne jamais activer en production.

**Aucune autre variable d'environnement nouvelle requise.**

## 4. CRON — Système de backup modulaire

Le nouveau système de backup remplace les anciens scripts `backup_data.php` et `restore_data.php`.

### Planification recommandée

```cron
# Backup complet quotidien à 02:00
0 2 * * * php /var/www/html/cmem2_API/src/cron/backup/run_all.php >> /var/log/cmem2_backup.log 2>&1

# Nettoyage hebdomadaire des anciens backups (dimanche 03:00)
0 3 * * 0 php /var/www/html/cmem2_API/src/cron/backup/cleanup_backups.php >> /var/log/cmem2_cleanup.log 2>&1
```

### Test manuel

```bash
php src/cron/backup/run_all.php
```

## 5. Vérifications post-déploiement

### Plugin Puzzle — vérification abonnement

```text
POST /puzzle/auth/verify-subscription  (device_token + purchase_token valide)
  → 200, "is_premium": true

POST /puzzle/carousel/replace-all  (device_token)
  → 403 si pas abonné (comportement normal)
  → 200 si abonné

GET /puzzle/themes  (device_token)
  → 403 si pas abonné (comportement normal)
  → 200 si abonné
```

## 6. Rollback

Aucune migration SQL — le rollback consiste à ré-uploader via FTP les fichiers
de la v2.2.4 pour les fichiers modifiés.

```text
src/puzzle/Routing/PuzzleRouteHandler.php  (depuis git show v2.2.4:<fichier>)
src/puzzle/config/puzzle_config.php
src/puzzle/Controllers/ThemeController.php
```
