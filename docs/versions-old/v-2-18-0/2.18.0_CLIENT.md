# v2.18.0 — Changements visibles client

## BREAKING CHANGES

### IA : quota en nombre d'appels → budget mensuel en dollars

`POST /ai/summarize` :

- Succès `200` : `data.quota` `{used, limit, reset_at}` disparaît, remplacé par
  `data.budget` `{spent_usd, limit_usd, reset_at}`.
- Refus : `429 AI_QUOTA_EXCEEDED` disparaît, remplacé par `429 AI_BUDGET_EXCEEDED` avec
  `errors.scope` = `user` (budget personnel atteint) ou `global` (plafond du serveur
  atteint) et `errors.budget`.
- `502` (échec de l'appel modèle) : rien n'est facturé.

`GET /modules` et `PATCH /modules/ia` : le module `ia` renvoie `quota: null` et un nouveau
champ `budget` (même objet). Les vues de groupe `GET/PATCH /groups/{id}/modules` exposent
encore l'ancien `quota`, qui n'est plus appliqué — ne plus l'afficher.

Clients prévenus : directive cmem_web #412.

```json
{
  "success": false,
  "message": "Budget IA mensuel atteint.",
  "errors": {
    "code": "AI_BUDGET_EXCEEDED",
    "scope": "user",
    "budget": { "spent_usd": 10.01, "limit_usd": 10, "reset_at": "2026-12-01 00:00:00" }
  }
}
```

## Ajouté

- `GET /ai/usage` (JWT) → `data.budget` `{spent_usd, limit_usd, reset_at}`, à afficher avant
  tout appel.
- Budget par défaut : 10 $ par mois et par personne, administrateurs compris ; plafond global
  du serveur : 30 $ par mois. Remise à zéro le 1er de chaque mois.

## Modifié

- Modèle de résumé : Claude Haiku 5.5, réflexion désactivée, sortie limitée à 512 tokens.
  Le format de la réponse (`summary`) est inchangé.
