# v2.7.0 — Changements clients

## BREAKING CHANGES

### Routes supprimées (HTTP 410)

| Ancienne route | Remplacement |
| - | - |
| `POST /puzzle/auth/register-device` | `POST /v2/devices/android/register` |
| `POST /puzzle/auth/verify-subscription` | `POST /v2/subscriptions/playstore/verify` |
| `GET /puzzle/auth/subscription-status` | `GET /v2/access/status?app_id=puzzle` |
| `GET /puzzle/auth/pseudonym` | `GET /v2/devices/android/pseudonym?app_id=puzzle` |
| `POST /puzzle/auth/pseudonym` | `POST /v2/devices/android/pseudonym` |
| `DELETE /puzzle/auth/pseudonym` | `DELETE /v2/devices/android/pseudonym` |
| `GET /puzzle/auth/check-pseudonym/{p}` | `GET /v2/devices/android/pseudonym/check/{p}` |
| `POST /subscription/checkout` | `POST /v2/billing/checkout` |
| `POST /subscription/portal` | `POST /v2/billing/portal` |
| `POST /stripe/webhook` | `POST /v2/billing/webhook` (Stripe Dashboard) |

### Routes puzzle versionnées

Toutes les routes `/puzzle/*` → `/v2/puzzle/*` :

- `GET /v2/puzzle/carousel`
- `POST /v2/puzzle/carousel/replace-one`
- `POST /v2/puzzle/carousel/replace-all`
- `GET /v2/puzzle/themes`
- `GET /v2/puzzle/themes/{slug}/images`
- `GET /v2/puzzle/thumb/{uid}`
- `GET /v2/puzzle/image/{uid}`
- `GET|POST /v2/puzzle/backup`
- `POST /v2/puzzle/backup/claim`
- `GET|POST|DELETE /v2/puzzle/shared[/*]`
- `GET|POST /v2/puzzle/admin/*`

### Champ `subscriptions` retiré de `POST /auth/login`

La réponse de `POST /auth/login` et `POST /auth/verify-code` ne contient plus le champ `subscriptions`.
Utiliser `GET /v2/access/status?app_id={app_id}` pour connaître l'état premium.

### Authentification Play Store

`POST /v2/subscriptions/playstore/verify` et `GET /v2/subscriptions/playstore/status`
requièrent `X-Device-Token` (device_token Android) — **plus de JWT**.

### Android anonyme

`POST /v2/devices/android/register` : JWT désormais optionnel.
Sans JWT → device anonyme créé (user_id = NULL).
