# v2.8.0 — Changements visibles client

## Nouveau module — Traque (gamification géolocalisée)

Plugin `src/traque/` disponible sous le préfixe `/traque`.

Fonctionnalités :

- Création de personnage (classe, race, stats, `character_name` unique)
- Monstres géolocalisés avec biomes OSM (`forest`, `peak`, `water`, `cemetery`, `worship`, `industrial`, `urban`)
- Sessions de combat au tour par tour (attaque, fuite, sauvegarde)
- Attaques spéciales : poison (`save_dc`, `save_stat=con`) et sorts (`save_stat=sag`)
- Repos hors combat : actif (50 % HP, cooldown 30 min) et complet (100 % HP, cooldown 4 h)
- Régénération passive : 1 HP / 5 min depuis la fin du dernier combat
- Achievements débloquables (7 définis au lancement)
- Leaderboard par classe, biome et global (affiche `character_name`)
- Vérification disponibilité du nom : `GET /traque/players/check-name?name=X`

## Ajout — Tags pour `quiz_questions`

Les questions de quiz peuvent maintenant recevoir des tags (`GET /quiz/{id}` expose `tags: [{id, name, color}]` par question).

La valeur `quiz_questions` est désormais acceptée dans les endpoints de tags (`table_associate`).

## Ajout — Upload `kestyon` en mode `grand-public`

Un utilisateur authentifié (non-admin) peut uploader dans le dossier `kestyon` avec `accessibility: grand-public`.

La réponse d'upload inclut désormais le champ `download_url` au format `{APP_URL}/files/{id}`.

## Fix — Comparaison date de naissance

La vérification de la date de naissance lors de la connexion se fait maintenant à minuit UTC pour éviter les décalages de fuseau horaire.
