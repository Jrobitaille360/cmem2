# cmem2 API — v2.10.0 — Checklist déploiement

Date : 2026-07-24
Cibles : **production** (`cmem2.journauxdebord.com`) et **dev** (`dev-cmem2.journauxdebord.com`)

> ⚠️ **Pas de `composer` sur le serveur.** Les dépendances sont déjà présentes dans

## 1. Migrations SQL

Trois migrations à appliquer (déjà appliquées sur **dev-cmem** — à faire sur **prod**) :

```sql
-- Dans l'ordre (dépendances FK) :
SET foreign_key_checks = 0;
SOURCE docs/v-2-10-0/20260721_projets_taches.sql;   -- projects, calendar_todos +5 cols, task_dependencies
SOURCE docs/v-2-10-0/20260722_links.sql;            -- links
SOURCE docs/v-2-10-0/20260723_contacts.sql;         -- contacts, contact_shares
SET foreign_key_checks = 1;
```

Nouvelle base à partir de zéro : `docs/v-2-10-0/build_DB-v-2.10.0.sql` (intègre les trois migrations).

Tables créées : `projects`, `task_dependencies`, `links`, `contacts`, `contact_shares`.
Colonnes ajoutées à `calendar_todos` : `project_id`, `parent_id`, `all_day`, `assignee`,
`remind_minutes_before`.
