# cmem2 API — v2.10.0 — Notes client

Date : 2026-07-24

## BREAKING CHANGES

- **Occurrences de calendrier matérialisées retirées** — les endpoints
  `GET /calendars/{id}/events/occurrences` et
  `GET /calendars/{id}/events/{eventId}/occurrences` répondent désormais `410 Gone`.
  Utiliser `GET /calendars/{id}/events/occurrences/expand` (expansion à la volée).
- `GET /calendars/{id}/events?expand_recurrence=true` ne développe plus les
  récurrences en occurrences ; il renvoie les événements parents. L'expansion passe
  exclusivement par `.../occurrences/expand`.
- **Google Play / AdMob désactivés pour `app_id=puzzle`** — les endpoints
  `POST /v2/subscriptions/playstore/verify`, `GET /v2/subscriptions/playstore/status`
  et `DELETE /v2/subscriptions/playstore` répondent `410 PROVIDER_DISABLED` pour
  `app_id=puzzle`. Stripe devient l'unique fournisseur d'abonnement pour puzzle.
  Aucun impact sur `cmem`, `kestyon`, `traque`.

## Nouveautés

### Pilier Contacts (`/contacts`)

- CRUD complet : `GET/POST /contacts`, `GET/PUT/PATCH/DELETE /contacts/{id}`.
- Filtres de liste `?q=`, `?categorie=`, `?favori=`, pagination `?limit=&offset=` avec `total`.
- Export vCard 4.0 : `GET /contacts/{id}.vcf`. Import vCard ou CSV : `POST /contacts/import`
  → rapport `{ crees, maj, ignores, erreurs[] }`.
- Nouveau cap de plan `max_contacts` (free 50, payant/ami 2000), exposé dans
  `GET /auth/me` → `plan.features`. Dépassement → `403 QUOTA_EXCEEDED`.
- Multi-tenant `app_id` à transmettre en création **et** en lecture de liste.

### Liens croisés inter-entités (`/links`)

- `POST /links`, `GET /links?type=&id=`, `DELETE /links/{id}`.
- Entités liables : `event`, `task`, `journal`, `project`, `project_task`.
- Lien bidirectionnel, dédup idempotente, portée owner-strict (`404` si une extrémité
  n'est pas visible par l'usager).

### Plugin Projets (`/projets`)

- Projets → tâches, hiérarchie (`parentId`), dépendances (`dependsOn[]` FS/SS/FF/SF).
- Export/import JSON round-trip, export `.ics` (VEVENT).
- Validation arbre/DAG (rejet des cycles) avant tout commit.

### Divers

- Tenant Stripe `cmemweb` : le tenant cmem couvre désormais les `app_id`
  `'cmemweb'` (primaire) et `'cmem'` (alias legacy).
- `POST /files` accepte les fichiers `.gpx` (`media_type=document`, max 10 MB).
