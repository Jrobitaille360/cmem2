## Migrations SQL

## Déploiement du code

- [ ] `git pull origin main` sur le serveur
- [ ] `composer install --no-dev --optimize-autoloader`

- [ ] `GET /subscription/status?app_id=puzzle` → sync Google Play en temps réel (vérifier logs)
- [ ] `APP_COMMIT` présent dans `.env` distant après déploiement via `deploy.ps1`
- [ ] Cron maintenance : vérifier qu'aucun courriel n'est envoyé si aucune erreur

Aucun nouveau cron. Aucun changement de configuration requis.
