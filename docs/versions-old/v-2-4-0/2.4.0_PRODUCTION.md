# Déploiement production — v2.4.0

## Prérequis

- Version précédente : 2.3.1
- PHP 8.0+
- MySQL 5.7+ / MariaDB 10.3+

---

## 1. Migration base de données

Appliquer dans l'ordre :

```bash
mysql -u root -p cmem2 < docs/v-2-4-0/20260423_files_media_type_executable.sql
mysql -u root -p cmem2 < docs/v-2-4-0/20260426_subscriptions_trial.sql
```

> En cas d'installation fraîche, utiliser `docs/v-2-4-0/build_DB-v-2.4.0.sql` directement.

---

## 2. Variables d'environnement

Ajouter dans `.env` si l'intégration Stripe est activée :

```
STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_PRICE_PUZZLE_MONTHLY=price_...
STRIPE_PRICE_PUZZLE_YEARLY=price_...
```

---

## 3. Déploiement du code

```bash
git pull origin main
composer install --no-dev --optimize-autoloader
```

---

## 4. Webhook Stripe (si applicable)

Configurer dans le tableau de bord Stripe :

- URL : `https://cmem2.journauxdebord.com/stripe/webhook`
- Événements : `checkout.session.completed`, `customer.subscription.updated`,
  `invoice.payment_succeeded`, `invoice.payment_failed`, `customer.subscription.deleted`

---

## 5. Cron — Maintenance centralisée

Ajouter au crontab :

```cron
0 3 * * * /usr/local/bin/php /home/lmdkhdg5/cmem2.journauxdebord.com/src/cron/maintenance.php >> /home/lmdkhdg5/logs/maintenance-$(date +\%Y-\%m-\%d).log 2>&1
5 3 * * * find /home/lmdkhdg5/logs/ -name "maintenance-*.log" -mtime +7 -delete
```

> Remplace les anciens scripts CRON individuels (`expire_subscriptions.php`, `cleanup.php`).
> Vérifier qu'aucun doublon n'existe dans le crontab existant.
