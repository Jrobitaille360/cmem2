# v2.17.4 — Changements visibles client

## Modifié

### Push : corps du rappel — date/heure réelle au lieu du délai

Directive cmem_web #210, task cmemweb #215.

Le corps (`body`) des notifications push de rappel pour `event`, `recurring` et
`task_due` affiche désormais la date/heure réelle de l'élément, dans le fuseau du compte
(`users.timezone`), au lieu du texte générique par délai (« vous avez un événement dans
5 minutes ») :

| Cas | `body` |
| - | - |
| Événement ponctuel (pas journée entière) | `14h30 - 15h00` |
| Événement journée entière, un seul jour | `3 sept.` |
| Événement journée entière ou multi-jours | `3 sept. - 5 sept.` |
| Tâche échue, avec heure | `3 sept. 14h05` |
| Tâche échue, journée entière | `3 sept.` |

`contact_followup` n'est pas concerné — le texte générique par délai est conservé (aucune
date/heure d'échéance unique et fiable à afficher pour ce kind).

Le `title` n'est pas affecté par ce changement — il reste régi par la préférence
`show_entity_detail` (v2.17.3).

## BREAKING CHANGES

Aucun. Le format du `body` change mais son type reste `string` — aucun contrat d'API
modifié (`data.type`/`data.id` inchangés).
