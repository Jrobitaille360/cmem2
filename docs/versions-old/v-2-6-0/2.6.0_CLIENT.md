# v2.6.0 — Changements visibles client

Date : 2026-05-10

## Nouvelles fonctionnalités

### Premium Windows/Web — lien de compte

Les utilisateurs Windows et Web qui ont un abonnement Stripe peuvent maintenant
lier leur appareil à leur compte cmem2 via un nouvel appel JWT au moment de la
connexion. Une fois lié, l'accès premium est reconnu immédiatement sans
réinstallation.

**Impact :** résout le bug signalé où les abonnés Stripe sur Windows/Web n'avaient
pas accès aux fonctionnalités premium.

### Google Play — abonnements fiabilisés

Le flux d'achat Google Play écrit maintenant directement dans la table centrale
des abonnements. Les scénarios suivants sont maintenant correctement gérés :

- **Réinstallation** : le même `purchase_token` retrouve l'accès premium
- **Upgrade/Downgrade** : l'ancien token est automatiquement expiré, le nouveau activé
- **Renouvellement** : la date d'expiration est mise à jour sans créer de doublon

## Corrections

- **Sauvegarde serveur** : le cron de backup des fichiers uploadés fonctionnait
  mal sur certains serveurs (erreur PharData). Remplacé par `tar` natif — fiabilité
  améliorée.

Aucun.
