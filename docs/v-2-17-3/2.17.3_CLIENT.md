# v2.17.3 — Changements visibles client

## Ajouté

### Push : titre réel de l'entité dans le rappel (opt-in)

Directive cmem_web, task cmemweb #199.

Par défaut, un push de rappel affiche un titre générique (« Rappel ») — le détail de
l'entité (titre événement, titre tâche, nom contact, titre opportunité) n'apparaît
jamais, même sur écran déverrouillé, pour protéger l'écran verrouillé.

Une nouvelle préférence opt-in par kind (`show_entity_detail`, défaut `false`)
permet d'afficher le titre réel de l'entité à la place du générique :

- `event` / `recurring` → titre de l'événement
- `task_due` → titre de la tâche
- `contact_followup` → nom du contact ou titre de l'opportunité

Le corps du push (`body`) reste toujours le texte générique par délai (« dans 15
minutes », etc.) — seul le titre change. `GET`/`PUT /push/preferences` exposent le
nouveau champ.

Le réglage front (bascule dans les préférences de notification, cmem_web) est livré
séparément — hors scope de cette version.
