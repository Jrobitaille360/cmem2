## Nouveau — Endpoint public Items (sans JWT)

### GET /items/publics

Liste tous les items dont `access = 'public'`, sans JWT requis.

```http
GET /items/publics
GET /items/publics?category=alpha&limit=20&offset=0
```

| Paramètre | Type | Description |
| - | - | - |
| `category` | string | Filtre par catégorie (virgule = plusieurs, OR) |
| `category_match` | `any` / `all` | Mode correspondance : `any` (défaut) ou `all` |
| `limit` | integer | Nombre max de résultats (défaut 20, max 200) |
| `offset` | integer | Décalage pour la pagination |

### GET /items/{id} sans JWT

Un item avec `access = 'public'` est désormais accessible sans authentification.
Les items `private` et `share` continuent de retourner 403 sans JWT valide.

## Nouveau — Paramètre `folder` sur POST /files

Le champ FormData `folder` permet de choisir le sous-dossier de destination :

```http
POST /files
Content-Type: multipart/form-data

file: <binaire>
folder: mon-app
description: Setup Windows
```

- Caractères autorisés : `a-z`, `0-9`, `-`, `_` ; max 80 caractères
- Si absent ou vide : comportement inchangé (`uploads/files/`)
- L'URL retournée reflète le dossier choisi : `/uploads/mon-app/setup.exe`

Exemples valides : `mon-app`, `setup_v2`, `jdb-windows`

---

## Nouveau — Types de fichiers exécutables et archives

`POST /files` accepte désormais les exécutables et archives Windows :

| Extension | MIME type | Taille max |
| - | - | - |
| `.exe` | `application/x-msdownload` / `application/x-dosexec` | 200 MB |
| `.msi` | `application/x-msi` | 200 MB |
| `.zip` | `application/zip` / `application/x-zip-compressed` | 200 MB |
| `.7z` | `application/x-7z-compressed` | 200 MB |

---

## Nouveau — GET /files?folder=\<slug\> (admin)

Route réservée aux ADMINISTRATEURS. Retourne tous les fichiers stockés dans un dossier donné.

```http
GET /files?folder=mon-app
Authorization: Bearer <jwt_admin>
```

Réponse :

```json
{
  "success": true,
  "data": {
    "files": [
      {
        "id": 12,
        "original_name": "setup.exe",
        "file_name": "abc123_setup.exe",
        "mime_type": "application/x-msdownload",
        "file_size": 52428800,
        "url": "/uploads/mon-app/abc123_setup.exe",
        "upload_date": "2026-04-23 10:00:00"
      }
    ],
    "folder": "mon-app",
    "total": 1
  }
}
```
