## 2. Variables `.env`

Une seule variable nouvelle :

```ini
ACCOUNT_PURGE_GRACE_DAYS=30
```

Délai de grâce avant effacement physique d'un compte supprimé. Absente, la valeur par défaut de
30 jours s'applique — la valeur annoncée dans la politique de confidentialité du client.

Ne pas oublier `APP_VERSION=2.12.0`.

## 4. Cron

**Aucun ajustement.** La purge des comptes supprimés est une tâche de `src/cron/maintenance.php`,
déjà planifié à 3 h 00 en production. Vérifier simplement que l'entrée existe :

```bash
crontab -l | grep maintenance.php
```

> ⚠️ **Avant la première exécution réelle sur un environnement où des comptes ont été supprimés
> il y a plus de 30 jours**, lancer le dry-run — la première purge traitera d'un seul coup tout
> l'arriéré :
>
> ```bash
> php src/cron/purge_accounts.php --dry-run
> ```
>
> Vérifié le 2026-08-02 en production : **0 compte éligible**, aucun arriéré.

## 5. Vérifications après déploiement

```bash
# Version et santé
curl -s https://cmem2.journauxdebord.com/health -o /dev/null -w "%{http_code}\n"   # 200
curl -s https://cmem2.journauxdebord.com/ | head -c 200                            # version 2.12.0

# Purge : rapport à vide sur un environnement sain
php src/cron/purge_accounts.php --dry-run

# Journal d'erreurs
tail -50 logs/app-$(date +%Y-%m-%d).log | grep -i 'error\|fatal'
```

Points de contrôle fonctionnels :

- `GET /auth/me` avec un JWT d'un compte supprimé → `401` `ACCOUNT_UNAVAILABLE` ;
- `POST /auth/send-code` sur un compte en délai de grâce → `409` `ACCOUNT_PENDING_DELETION` ;
- `DELETE /users/me` → réponse contenant `purge_scheduled_at` ;
- `GET /modules` avec un JWT valide → liste des modules avec `available` / `enabled`.

## 6. Retour arrière

Le code est réversible par redéploiement du commit précédent. Les migrations ne le sont pas
sans perte :

- `tenant_modules` et `billing_archive` peuvent être conservées sans effet sur l'ancien code ;
- les colonnes `attempts` / `max_attempts` ont des valeurs par défaut et sont ignorées par
  l'ancien code.

Aucun `DROP` n'est nécessaire pour revenir en arrière.
