# v2.25.0 — Changements visibles client

Nouveau plugin `jesaisquand` (« Je sais quand », directives #524 et #526). Aucune route
existante n'est modifiée.

## BREAKING CHANGES

Aucun.

## Ajouté

- Paquets de cartes chronologiques :
  - `GET /jesaisquand/paquets` : paquets publics, sans cartes ;
  - `GET /jesaisquand/paquets/{slug}` : cartes avec dates, au format client jesaisquand.
- Multijoueur au tour par tour, joueurs invités (pseudo + jeton joueur à conserver) :
  - `POST /jesaisquand/parties` et `POST /jesaisquand/parties/{code}/rejoindre`
    (2 à 6 joueurs, JWT facultatif pour rattacher le joueur à son compte) ;
  - `POST /jesaisquand/parties/{code}/demarrer` (créateur) ;
  - `GET /jesaisquand/parties/{code}?depuis={version}` (`304` si inchangé) ;
  - `POST /jesaisquand/parties/{code}/coups`.
- Le serveur fait autorité : les cartes en main n'exposent jamais `date`, `dateTexte`,
  `periode`, `approx`, `essentiel` ni `description`.
- Pas de délai par tour ; une partie inactive depuis 24 h passe à `expiree` (`410`).
- Administration (`ADMINISTRATEUR` / `SUPERADMINISTRATEUR`) :
  - `POST /jesaisquand/admin/paquets` : import upsert d'un paquet JSON jesaisquand ;
  - `PATCH /jesaisquand/paquets/{slug}/cartes/{carte_id}` : illustration (`image_url` https
    sur `upload.wikimedia.org` / `images-assets.nasa.gov`, ou `image_file_id` cmem2
    grand-public) et crédit obligatoire, modifications journalisées ;
  - `GET /jesaisquand/admin/cartes-sans-credit?paquet=`.

Référence : `docs/docs-api/jesaisquand/GUIDE.md` et `API_JESAISQUAND_ENDPOINTS.json`.
