# v2.24.0 — Changements visibles client

Le module **Assistant** permet maintenant à l'usager d'envoyer ses **rappels par courriel avec
son propre serveur SMTP**. Aucune rupture : un usager qui ne configure rien continue de recevoir
ses rappels par le SMTP de Journaux de Bord. Référence complète :
`docs/docs-api/assistant/GUIDE.md` (section « Serveur SMTP personnel ») et
`API_ASSISTANT_ENDPOINTS.json` (groupe `smtp`).

## BREAKING CHANGES

Aucun.

## Ajouté

### Routes `/assistant/smtp` (JWT, module `assistant` coché et activé)

| Méthode | Route | Rôle |
| - | - | - |
| `GET` | `/assistant/smtp` | Paramètres enregistrés, sans mot de passe (`has_password`, `verified_at`) |
| `PUT` | `/assistant/smtp` | Crée ou remplace ; `password` omis = conservé |
| `DELETE` | `/assistant/smtp` | Supprime ; retour au SMTP système |
| `POST` | `/assistant/smtp/test` | Teste connexion, STARTTLS et authentification sans envoyer de courriel |

Parcours conseillé : `POST /assistant/smtp/test` avec les paramètres saisis, puis
`PUT /assistant/smtp`, puis éventuellement `POST /assistant/smtp/test {"send_to_self": true}`
(sans `host`) pour recevoir un vrai courriel de test et marquer les paramètres vérifiés.

### Champs

| Champ | Valeurs |
| - | - |
| `host` | Nom d'hôte ou IPv4 publique (adresses privées, locales, réservées refusées) |
| `port` | 1 à 65535 |
| `encryption` | `tls` (STARTTLS, défaut), `ssl` (TLS implicite), `none` |
| `username`, `password` | Mot de passe requis à la création si `username` est renseigné ; jamais renvoyé |
| `from_email`, `from_name` | Expéditeur des rappels |

### Comportement des rappels

Un rappel courriel part par le SMTP de l'usager ; si ce serveur échoue, il repart par le SMTP
de Journaux de Bord. Le courriel contient désormais une version HTML et une version texte
quand il passe par le SMTP de l'usager.

### Nouveaux codes d'erreur

| HTTP | Code | Cause |
| - | - | - |
| 404 | `SMTP_NOT_CONFIGURED` | Aucun SMTP personnel enregistré |
| 422 | `SMTP_HOST_FORBIDDEN` | Hôte privé, local ou réservé |
| 422 | `SMTP_HOST_UNREACHABLE` | Hôte introuvable ou injoignable |
| 422 | `SMTP_TLS_FAILED` | Chiffrement refusé ou certificat invalide |
| 422 | `SMTP_AUTH_FAILED` | Identifiant ou mot de passe refusé |
| 422 | `SMTP_SEND_FAILED` | Connexion correcte, envoi du courriel de test refusé |
| 429 | `SMTP_TEST_RATE_LIMITED` | Plus de 5 tests en 10 minutes |
| 503 | `SMTP_KEY_NOT_CONFIGURED` | Chiffrement non configuré côté serveur |
