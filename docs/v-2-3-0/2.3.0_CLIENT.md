## Nouveau — Plugin Items Manager

La v2.3.0 introduit un gestionnaire générique d'items accessible sous le préfixe `/items`.

### Authentification

Tous les endpoints `/items/*` exigent un JWT valide :

```http
Authorization: Bearer <jwt_token>
```

### Modes d'accès

Chaque item porte un mode `access` :

| Valeur | Qui peut lire | Qui peut modifier le contenu |
| - | - | - |
| `private` | owner, admin | owner, admin |
| `share` | owner, admin, invités listés | owner, admin, invités avec `can_update=1` |
| `public` | tout JWT valide | tout JWT valide |

Changer le mode ou gérer les invités est réservé au **propriétaire** ou à un **administrateur**.

### Endpoints disponibles

| Méthode | Route | Auth | Description |
| - | - | - | - |
| GET | `/items` | JWT | Liste des items accessibles |
| POST | `/items` | JWT | Créer un item |
| GET | `/items/categories` | JWT | Catégories distinctes accessibles |
| GET | `/items/categories/{name}` | JWT | Items d'une catégorie |
| GET | `/items/{id}` | JWT | Lire un item |
| PUT | `/items/{id}` | JWT | Mettre à jour `categories` / `json_item` |
| DELETE | `/items/{id}` | JWT (owner/admin) | Supprimer (soft-delete) |
| PUT | `/items/{id}/access` | JWT (owner/admin) | Changer le mode d'accès |
| GET | `/items/{id}/shares` | JWT | Lister les invités |
| POST | `/items/{id}/shares` | JWT (owner/admin) | Ajouter un invité |
| PUT | `/items/{id}/shares/{user_id}` | JWT (owner/admin) | Modifier can_update d'un invité |
| DELETE | `/items/{id}/shares/{user_id}` | JWT (owner/admin) | Retirer un invité |

### Filtres `GET /items`

```http
GET /items?owner=all&category=alpha,beta&category_match=any&limit=20&offset=0
```

- `owner=me` (défaut) : items propres uniquement
- `owner=all` : propres + partagés + publics
- `category=a` ou `category=a,b,c` : filtre par catégorie (OR par défaut)
- `category_match=all` : passe en mode AND (toutes les catégories requises)
- `limit` / `offset` : pagination (max 200)

### Structure d'un item (réponse)

```json
{
  "id": 1,
  "owner_user_id": 42,
  "access": "share",
  "categories": ["alpha", "beta"],
  "json_item": { "titre": "Mon item" },
  "created_at": "2026-04-15 20:00:00",
  "updated_at": "2026-04-15 20:00:00"
}
```

> Le champ `json_item` est retourné décodé (objet ou tableau PHP/JSON), jamais comme chaîne brute.

## Autres changements (depuis v2.2.4)

### Sécurité — Refresh token rotatif (v2.2.5-like, inclus dans 2.3.0)

- `POST /auth/refresh` — rotation du device token à chaque appel (famille partagée)
- Détection des replay attacks : présentation d'un token révoqué → révocation de toute la famille
- `GET /auth/sessions` — vue unifiée des sessions JWT actives et des appareils de confiance
- `DELETE /auth/sessions` — déconnexion globale (tous appareils)
